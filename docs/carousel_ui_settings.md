# Carousel UI Settings Reference

Этот документ описывает параметры генерации карусели в интерфейсе и их влияние на итоговый результат.

## Основные параметры

- `topic` - тема карусели, используется для генерации структуры и текста слайдов.
- `lang` - язык генерации (`ru`, `en`, `auto`).
- `slide_count` - количество слайдов.
- `user_text` - готовый текст от пользователя; если передан, он становится источником контента вместо генерации с нуля.
- `ref_style_images[]` - референсы стиля для палитры и визуального характера.
- `subject_image` - объект/человек для вырезания и размещения в hero-зоне.
- `brand_assets[]` - дополнительные брендовые материалы (логотипы, элементы стиля).

## Экспорт и холст

- `export_format` - формат итоговых слайдов (`png`, `jpg`).
- `jpg_quality` - качество JPEG при экспорте.
- `canvas_w`, `canvas_h` - размер холста (в текущем flow фиксирован 1080x1350).

## Safe Margins

- `safe_top`, `safe_bottom`, `safe_left`, `safe_right` - безопасные отступы для текста и ключевых блоков.
- Чем больше значения, тем выше шанс избежать обрезки интерфейсом Instagram, но меньше полезная площадь.

## Цвета

- `color_bg` - основной цвет фона.
- `color_text_main` - основной цвет заголовков и текста.
- `color_text_muted` - приглушенный цвет вторичных подписей.
- `color_accent` - основной акцентный цвет.
- `color_accent_2` - второй акцентный цвет.
- `color_cta_bar` - цвет подложки CTA-плашки.
- `highlight_style` - стиль акцента текста (`fill`, `underline`, `glow`).

## Типографика

- `font_h1_family`, `font_body_family` - семейства шрифтов.
- `font_h1_weight`, `font_body_weight` - насыщенность шрифтов.
- `font_h1_size` - стартовый размер заголовка.
- `font_body_size` - стартовый размер буллетов/основного текста.
- `font_caption_size` - размер подписи/CTA.
- `line_height_h1`, `line_height_body` - межстрочный интервал.
- `letter_spacing_h1` - межбуквенное расстояние заголовков.

## Эффекты текста

- `text_stroke_width` - толщина обводки текста.
- `text_stroke_color` - цвет обводки.
- `text_shadow_xy` - смещение тени.
- `text_shadow_blur` - размытие тени.
- `text_shadow_color` - цвет тени.
- `text_glow_intensity` - интенсивность свечения.

## Фоновые FX

- `fx_vignette_intensity` - интенсивность виньетки.
- `fx_grain_amount` - количество зерна/шума.
- `fx_lightning_density` - плотность неоновых линий.
- `fx_lightning_thickness` - толщина линий.
- `fx_neon_blur` - размытие неона.
- `fx_neon_line_width` - ширина неоновых штрихов.

## Layout и композиция

- `layout_preset` - базовый пресет раскладки (`hero_left`, `hero_right`, `text_only`, `cards_grid`).
- `hero_enabled` - включает hero-композицию.
- `hero_side` - сторона hero-блока (`left` или `right`).
- `hero_scale` - масштаб блока героя.

## Карточки и формы

- `card_radius` - скругление карточек.
- `card_shadow` - интенсивность тени карточек.
- `card_stroke` - толщина обводки карточек.
- `text_card_outline_enabled` - включает/выключает обводку подложек заголовка и буллетов.

## CTA

- `cta_enabled` - включение CTA-блока.
- `cta_text` - текст CTA по умолчанию.
- `cta_position` - положение CTA (`top` или `bottom`).
- `allow_illustration_on_last_slide` - разрешает показывать декоративный ассет на завершающем слайде.

## Как читать ползунки в UI

- Размеры шрифтов и отступов влияют на влезание текста в safe-area.
- Эффекты (`shadow`, `glow`, `stroke`) повышают читаемость, но могут визуально утяжелять макет.
- Цвета и акценты лучше настраивать после загрузки `ref_style_images[]`, чтобы сохранить стиль.
- При QA-ошибках сначала снижайте `font_h1_size` и `font_body_size`, затем увеличивайте `safe_*`.
